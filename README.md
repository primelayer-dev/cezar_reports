# cezar_reports

Публічний репозиторій для звітів про перевірку стану роботи в репозиторії `Milesign`.

## Вміст

| Файл | Призначення |
| --- | --- |
| `latest.md` | Найсвіжіший перевірений звіт про стан конкретного pull request |
| `README.md` | Цей опис |

## Правила ведення звітів

- Кожен звіт описує фактичний стан, перевірений безпосередньо перед публікацією,
  а не переказ попередніх звітів.
- Стан pull request (гілка, базова гілка, SHA, кількість змінених файлів)
  береться з GitHub API на момент перевірки.
- Результати перевірок (встановлення залежностей, lint, типи, збірка, тести)
  отримані фактичним запуском відповідних команд.
- Звіти навмисно не містять вихідного коду, повних журналів команд, локальних
  шляхів, змінних середовища, токенів, ключів, паролів чи інших закритих даних —
  лише статуси, підсумки та висновки.
- Звіти є довідковими: вони нічого не змінюють у репозиторії `Milesign`.
